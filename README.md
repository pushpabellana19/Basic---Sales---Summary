# Task 14 – Basic Sales Summary

## Project Overview
This project focuses on creating a basic sales summary using a Retail Sales Dataset in Google Sheets. The objective is to calculate important business KPIs to understand overall sales performance.

## Dataset
- Retail Sales Dataset
- Tool Used: Google Sheets

## Key Performance Indicators (KPIs)

1. **Total Sales:** Calculated using the SUM() formula.
2. **Average Sales:** Calculated using the AVERAGE() formula.
3. **Transaction Count:** Calculated using the COUNTA() formula.

## Formulas Used

- `=SUM('retail sales dataset'!I2:I)`
- `=AVERAGE('retail sales dataset'!I2:I)`
- `=COUNTA('retail sales dataset'!A2:A)`
